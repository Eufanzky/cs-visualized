## ✨ Why

Reading pseudocode tells you *what* an algorithm does. Watching the array actually swap tells you *why*. Every animation here is driven by the real algorithm — the steps aren't hand-drawn, they're generated by running the code and recording each state transition.

- ▶️ **Playback controls** — play, pause, step forward/back, adjust speed
- 🎨 **Purpose-built renderers** — bar charts for sorts, node graphs for traversals, grids for DP tables, neurons for networks
- 🎵 **Lofi soundtrack + sound effects**, because studying is easier with a beat
- 🧪 **Unit-tested** step generators, so what you see matches what the algorithm really does

## 🏗️ How It Works

The core idea is that **algorithms produce data, not pixels**. Each algorithm is a *step generator*: a pure function that takes an input and returns an array of state transitions (`compare`, `swap`, `set`, `highlight`). A small engine applies those steps to a scene, and a renderer draws the scene to a canvas.

```
algorithm (pure fn)  →  AnimationStep[]  →  engine (applyStep)  →  renderer  →  <canvas>
```

That separation means an algorithm can be unit-tested with no DOM involved, and a new renderer can be dropped in without touching any algorithm.

| Module | Responsibility |
|:-------|:---------------|
| `src/lib/algorithms/` | Step generators — one file per algorithm, plus a registry |
| `src/lib/animation-engine.ts` | Core types and the state machine (`applyStep`, `reset`) |
| `src/lib/renderers/` | Draw functions: `bar-chart`, `graph`, `tree`, `linear`, `hash-table`, `dp-grid`, `neuron` |
| `src/lib/categories.ts` | Single source of truth for categories and animation metadata |
| `src/hooks/useAnimation.ts` | Wires the canvas ref, playback controls and step execution together |

## ➕ Adding an Algorithm

1. Create `src/lib/algorithms/{id}.ts` exporting a `StepGenerator`.
2. Register it in `src/lib/algorithms/index.ts` with its metadata and `rendererType`.
3. Add an entry to the matching category in `src/lib/categories.ts` with `status: 'ready'`.
4. Need a new visual? Add `src/lib/renderers/{type}.ts` and register it.
