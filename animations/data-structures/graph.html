Graph

A collection of nodes (vertices) connected by edges — the most versatile structure for modeling relationships.

Speed

Complexity

Add vertex: O(1)

Add edge: O(1)

BFS/DFS: O(V + E)

Space: O(V + E) adjacency list

Adjacency list is space-efficient for sparse graphs.

How It Works

01 Vertices store data, edges connect vertices
02 BFS explores level by level (uses queue)
03 DFS explores as deep as possible first (uses stack)
04 Undirected: edges go both ways
05 Applications: social networks, maps, dependencies
