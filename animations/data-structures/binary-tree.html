Binary Search Tree

A hierarchical structure where each node has at most two children, with left < parent < right ordering.

Speed

Complexity

Search: O(log n) average, O(n) worst

Insert: O(log n) average, O(n) worst

Delete: O(log n) average, O(n) worst

Worst case occurs when tree degenerates into a linked list.

How It Works

01 Each node has at most two children (left, right)
02 Left subtree values < node value
03 Right subtree values > node value
04 Search: compare and go left or right
05 In-order traversal yields sorted sequence
