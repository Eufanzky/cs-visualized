Hash Table

Maps keys to values using a hash function — achieving near-constant time lookups with collision handling via chaining.

Speed

Complexity

Insert: O(1) average, O(n) worst

Lookup: O(1) average, O(n) worst

Delete: O(1) average, O(n) worst

Worst case when all keys collide into the same bucket.

How It Works

01 Hash function converts key → bucket index
02 Element stored in the computed bucket
03 Collisions: multiple keys map to same bucket
04 Separate chaining: bucket holds a linked list
05 Good hash function distributes keys uniformly
