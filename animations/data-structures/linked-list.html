Linked List

A linear collection of nodes where each element points to the next — enabling efficient insertion and deletion.

Speed

Complexity

Insert at head: O(1)

Insert at tail: O(n) singly linked

Search: O(n) — linear traversal

Delete: O(n) — must find predecessor

Dynamic size — no wasted memory from pre-allocation.

How It Works

01 Each node stores data and a pointer to the next node
02 HEAD pointer references the first node
03 Traversal follows pointers from HEAD to NULL
04 Insert at head: new node points to old head
05 Delete: update predecessor's pointer to skip node
