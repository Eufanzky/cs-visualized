Array

A contiguous block of memory storing elements at indexed positions — the most fundamental data structure.

Speed

Complexity

Access: O(1) — direct index lookup

Search: O(n) — linear scan

Insert/Delete: O(n) — shifting elements

Contiguous memory layout provides excellent cache performance.

How It Works

01 Elements stored in contiguous memory locations
02 Each element accessed by its numeric index
03 Insertion at end is O(1) if space available
04 Insertion/deletion in middle requires shifting
05 Fixed or dynamically resizable capacity
