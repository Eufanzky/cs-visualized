Min-Heap

A complete binary tree where every parent is smaller than its children — enabling efficient priority queue operations.

Speed

Complexity

Insert: O(log n) — bubble up

Extract Min: O(log n) — bubble down

Find Min: O(1) — root element

Space: O(n)

Stored as an array; parent of i is at (i-1)/2.

How It Works

01 Complete binary tree stored as array
02 Min-heap property: parent ≤ children
03 Insert: add at end, then bubble up
04 Extract min: remove root, move last to root, bubble down
05 Bubble = swap with parent/child until heap property holds
