Queue

A First-In, First-Out (FIFO) collection — elements are added at the rear and removed from the front.

Speed

Complexity

Enqueue: O(1)

Dequeue: O(1)

Peek: O(1)

Search: O(n)

Used in BFS, task scheduling, and buffering.

How It Works

01 Enqueue adds element to the REAR
02 Dequeue removes element from the FRONT
03 Peek returns front element without removing
04 Maintains insertion order (FIFO)
05 Can be implemented with array or linked list
