Stack

A Last-In, First-Out (LIFO) collection — the most recently added element is the first to be removed.

Speed

Complexity

Push: O(1)

Pop: O(1)

Peek: O(1)

Search: O(n)

Used in function call stacks, undo operations, and expression parsing.

How It Works

01 Push adds element to the top of the stack
02 Pop removes and returns the top element
03 Peek returns top element without removing
04 Only the top element is accessible
05 LIFO: Last In, First Out ordering
