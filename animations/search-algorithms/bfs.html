Breadth-First Search

Explore a graph level by level, visiting all neighbors before moving deeper.

Speed

Complexity

Time: O(V + E)

Space: O(V)

Finds shortest path in unweighted graphs. Uses a queue (FIFO).

How It Works

01 Enqueue the start node, mark as visited
02 Dequeue a node, process it
03 Enqueue all unvisited neighbors
04 Repeat until queue is empty
05 All reachable nodes are visited level by level
