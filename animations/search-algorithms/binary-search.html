Binary Search

Efficiently find a target value in a sorted array by repeatedly halving the search range.

Speed
Size

Complexity

Time: O(log n) worst / average

Time: O(1) best (target at midpoint)

Space: O(1) auxiliary

Requires sorted input. Divide-and-conquer strategy.

How It Works

01 Set low = 0 and high = n - 1
02 Compute mid = floor((low + high) / 2)
03 Compare target with arr[mid]
04 If equal, found. If target < mid, search left half
05 If target > mid, search right half. Repeat.
