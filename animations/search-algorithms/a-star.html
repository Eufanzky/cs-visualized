A* Search

Find the shortest path on a grid using heuristic-guided search that combines cost-so-far with estimated cost-to-goal.

Speed

Complexity

Time: O(E) worst case (E = edges)

Space: O(V)

Optimal with admissible heuristic. Combines Dijkstra's algorithm with greedy best-first search.

How It Works

01 f(n) = g(n) + h(n) where g = cost so far, h = heuristic
02 Add start to open set with f = h(start)
03 Pick node with lowest f from open set
04 Expand neighbors, update costs if better path found
05 Reconstruct path when goal is reached
