Depth-First Search

Explore as far as possible along each branch before backtracking.

Speed

Complexity

Time: O(V + E)

Space: O(V)

Useful for cycle detection, topological sorting, and path finding. Uses a stack (LIFO).

How It Works

01 Push the start node onto the stack
02 Pop a node, mark it as visited
03 Push all unvisited neighbors onto the stack
04 Backtrack when no unvisited neighbors remain
05 Repeat until stack is empty
