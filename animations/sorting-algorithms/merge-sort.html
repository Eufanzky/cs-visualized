Merge Sort

Divide the array in half recursively, sort each half, then merge the sorted halves back together.

Speed
Size

Complexity

Time: O(n log n) worst / average / best

Space: O(n) auxiliary

Stable sort — equal elements maintain relative order.

How It Works

01 Divide the array into two halves
02 Recursively sort each half
03 Compare front elements of both halves
04 Place the smaller element into the merged result
05 Repeat until all elements are merged
