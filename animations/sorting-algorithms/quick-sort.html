Quick Sort

Choose a pivot element, partition the array so smaller elements go left and larger go right, then recursively sort the partitions.

Speed
Size

Complexity

Time: O(n log n) average

Time: O(n²) worst (sorted input)

Space: O(log n) auxiliary (call stack)

Not stable — equal elements may change relative order.

How It Works

01 Choose the last element as pivot
02 Partition: elements < pivot go left
03 Elements > pivot go right
04 Place pivot in its final position
05 Recursively sort left and right partitions
