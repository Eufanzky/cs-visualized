Bubble Sort

Repeatedly step through the list, compare adjacent elements, and swap them if they're in the wrong order.

Speed
Size

Complexity

Time: O(n²) worst / average

Time: O(n) best (already sorted)

Space: O(1) auxiliary

Stable sort — equal elements maintain relative order.

How It Works

01 Compare adjacent elements
02 Swap if left > right
03 Largest element "bubbles" to the end
04 Repeat for remaining unsorted portion
05 Stop when no swaps occur in a pass
