Insertion Sort

Build a sorted portion one element at a time by inserting each new element into its correct position.

Speed
Size

Complexity

Time: O(n²) worst / average

Time: O(n) best (already sorted)

Space: O(1) auxiliary

Stable sort — equal elements maintain relative order.

How It Works

01 Take the next unsorted element
02 Compare with sorted portion from right to left
03 Shift larger elements one position right
04 Insert the element in its correct position
05 Repeat until the entire array is sorted
