Fibonacci with Memoization

Visualize the recursion tree for Fibonacci and see how memoization eliminates redundant computation.

Speed
N

Complexity

Time: O(n) with memoization

Time: O(2n) naive recursive

Space: O(n) memo table + call stack

Memoization converts exponential to linear by caching subproblem results.

How It Works

01 Call fib(n) recursively: fib(n) = fib(n-1) + fib(n-2)
02 Before computing, check memo table for cached result
03 If cached, return immediately (cache hit)
04 If not, compute and store result in memo table
05 Memoization prunes the recursion tree dramatically
