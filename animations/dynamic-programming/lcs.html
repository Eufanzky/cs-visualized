Longest Common Subsequence

Find the longest subsequence common to two strings using dynamic programming.

Speed

Complexity

Time: O(mn) where m, n are string lengths

Space: O(mn) for the DP table

Classic DP problem with applications in diff tools, bioinformatics, and version control.

How It Works

01 Build table with rows = chars of A, cols = chars of B
02 If chars match: dp[i][j] = dp[i-1][j-1] + 1 (diagonal)
03 If not: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
04 Bottom-right cell = LCS length
05 Backtrack to recover the actual subsequence
