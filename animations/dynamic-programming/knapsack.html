0/1 Knapsack

Maximize the total value of items placed in a knapsack with limited capacity using dynamic programming.

Speed

Complexity

Time: O(nW) pseudo-polynomial

Space: O(nW) for the DP table

NP-hard in general, but DP gives pseudo-polynomial solution when W is small.

How It Works

01 Create table: rows = items, columns = capacities 0..W
02 For each cell, decide: include item or skip it
03 dp[i][w] = max(skip, value[i] + dp[i-1][w-weight[i]])
04 Bottom-right cell contains optimal value
05 Backtrack to find which items were selected
