Dijkstra's Algorithm

Find the shortest path from a source node to all other nodes in a weighted graph with non-negative edge weights.

Speed

Complexity

Time: O(V²) naive implementation

Time: O(E log V) with priority queue

Space: O(V)

Only works with non-negative edge weights.

How It Works

01 Set distance to source = 0, all others = ∞
02 Pick unvisited node with smallest distance
03 For each neighbor, check if path through current is shorter
04 Update distance if shorter path found (relaxation)
05 Mark current node as finalized; repeat until all visited
