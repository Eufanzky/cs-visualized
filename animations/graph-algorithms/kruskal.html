Kruskal's Algorithm

Build a minimum spanning tree by greedily adding the smallest edge that doesn't form a cycle, using Union-Find.

Speed

Complexity

Time: O(E log E) dominated by edge sorting

Space: O(V) for Union-Find

Greedy algorithm — always picks the globally smallest safe edge.

How It Works

01 Sort all edges by weight (ascending)
02 Initialize Union-Find with each node in its own set
03 Consider edges in sorted order
04 Accept edge if it connects two different components
05 Reject edge if it would form a cycle
