Prim's Algorithm

Grow a minimum spanning tree one vertex at a time, always adding the cheapest edge connecting the tree to a new vertex.

Speed

Complexity

Time: O(E log V) with priority queue

Time: O(V²) with adjacency matrix

Space: O(V)

Greedy algorithm — grows a single tree from the starting vertex.

How It Works

01 Start from node 0 and add it to the MST
02 Find all edges connecting MST to non-MST vertices
03 Select the edge with minimum weight
04 Add the new vertex and edge to the MST
05 Repeat until all vertices are in the MST
