Topological Sort

Order vertices of a directed acyclic graph (DAG) so that every edge goes from earlier to later in the ordering. Uses Kahn's BFS-based algorithm.

Speed

Complexity

Time: O(V + E)

Space: O(V)

Only works on DAGs (directed acyclic graphs). Used for task scheduling, build systems, and course prerequisites.

How It Works

01 Compute in-degree for every vertex
02 Enqueue all vertices with in-degree 0
03 Dequeue a vertex, add it to the result
04 Decrement in-degrees of its neighbors
05 Enqueue any neighbor whose in-degree reaches 0
