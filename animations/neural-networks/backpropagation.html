Backpropagation

Visualize how gradients flow backward through a neural network to update weights during training.

Speed

Complexity

Time: O(n) per pass, where n = number of weights

Forward pass computes activations layer by layer

Backward pass computes gradients via the chain rule

The fundamental algorithm that enables deep learning.

How It Works

01 Forward: input propagates through layers
02 Compute loss at the output
03 Backward: compute gradients using chain rule
04 Update weights: w -= learning_rate * gradient
05 Repeat until loss converges
