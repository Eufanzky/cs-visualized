Single Perceptron

Watch a single neuron learn to classify linearly separable data by adjusting its weights and bias.

Speed
LR

Complexity

Converges in finite steps for linearly separable data

Update rule: w += lr * (target - output) * x

The simplest neural network — a single neuron with step activation.

How It Works

01 Compute weighted sum: z = w1*x1 + w2*x2 + bias
02 Apply step activation: output = z >= 0 ? 1 : 0
03 Compute error: error = target - output
04 Update weights: w += learning_rate * error * x
05 Repeat until all points classified correctly
