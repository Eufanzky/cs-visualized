Gradient Descent Optimization

Watch a point roll downhill on a loss surface, following the negative gradient to find the minimum.

Speed
Learning Rate

Complexity

Time: O(iterations * parameters)

Each step computes gradient and updates parameters

Foundation of neural network training. Learning rate controls step size — too high causes oscillation, too low causes slow convergence.

How It Works

01 Start at a random point on the loss surface
02 Compute the gradient (direction of steepest ascent)
03 Move in the opposite direction (negative gradient)
04 Scale the step by the learning rate
05 Repeat until loss converges to a minimum
