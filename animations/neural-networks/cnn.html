Convolutional Neural Network

Watch a convolution kernel slide across an input image, producing feature maps and pooled outputs.

Speed

Complexity

Convolution: O(k² * n² * c) per layer

k = kernel size, n = spatial dims, c = channels

Weight sharing makes CNNs translation invariant and parameter-efficient.

How It Works

01 Slide a small kernel across the input image
02 At each position, compute element-wise product and sum
03 Apply activation (ReLU) to get feature map
04 Max pooling reduces spatial dimensions
05 Stack layers to learn hierarchical features
